# Decisions
* [Deployed Auto mode stays on free routes](worker-auto-free-routes.md) - The deployed Worker's Auto mode uses only Gemini and then Groq; the OpenAI fallback is opt-in for local development through .dev.vars.
* [Abstracts are source text, never generated](abstracts-source-text-only.md) - A literature record's abstract is the source's own text; a work without a reliable abstract keeps a bibliographic chunk and a null abstract, never generated text.
* [Author and citation edges only from structured metadata](authors-from-structured-metadata.md) - The literature graph creates author nodes only from verified structured names and never parses inconsistent citation strings to invent authors or work-to-work citation edges.
* [Operational values come from live tools](live-first-operational-data.md) - Stable knowledge is indexed in Graph-RAG, while operational values that change after a build are queried through live MCP tools with labelled, timestamped snapshot fallback.
* [The Chronfix correction applies only to the HYS14 OBS clock](hys14-clock-correction-scope.md) - The bundled Chronfix clock correction belongs to the OO.HYS14 Hydrate Ridge ocean-bottom seismometer and is never applied to PREST, VEL3D, other instruments or already-corrected UTC.
* [The map gateway reuses the agent toolkits](gateway-reuses-toolkits.md) - The Atlas map gateway calls the Nereus, QA/QC, PI portal and EarthScope toolkits through their public methods instead of reimplementing them, so it inherits their host allowlists, bounds and sanitizers.
* [ARCADA is shown as RCA Information, with its internal id kept](arcada-display-name.md) - The arcada collection is presented to users as RCA Information, while its stable internal ID arcada, upstream identifiers and source URLs stay unchanged for reproducibility and attribution.
* [Model champions come only from RCA Atlas results](model-champions-from-rca-evaluation.md) - Answer and embedding models are chosen only from frozen-evidence and end-to-end RCA Atlas evaluations, never from public benchmarks; the answer champion stays unselected until a credentialed run.
